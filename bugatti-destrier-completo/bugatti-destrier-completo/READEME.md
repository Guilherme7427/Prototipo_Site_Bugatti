# 🏎️ Bugatti Clone - Protótipo Web

> Projeto acadêmico desenvolvido para a disciplina de Análise e Desenvolvimento de Sistemas, com o objetivo de recriar a experiência visual, interativa e de alta performance do site oficial da **Bugatti**.

---

## 📌 Sobre o Projeto

Este projeto consiste na recriação de uma landing page inspirada na estética de luxo, sofisticação e alta performance da Bugatti. Focado em **Front-End**, o protótipo foi construído utilizando apenas tecnologias nativas da web, sem o uso de frameworks ou bibliotecas pesadas, valorizando a lógica de programação, o design responsivo e a manipulação do DOM.

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido inteiramente com as seguintes tecnologias:

*   **HTML5:** Estruturação semântica e acessível da página.
*   **CSS3:** Estilização avançada (Flexbox, Grid, Variáveis CSS, Animações e Design Responsivo).
*   **JavaScript (Vanilla ES6+):** Lógica de interatividade, manipulação de elementos dinâmicos e controle de eventos.

---

## ✨ Funcionalidades do Protótipo

*   **Design Responsivo:** Adaptado para diferentes tamanhos de tela (Desktops, Tablets e Smartphones).
*   **Galeria Interativa / Vitrine de Modelos:** Seção dedicada a exibir os hipercarros da marca com transições suaves.
*   **Menu de Navegação Dinâmico:** Cabeçalho fixo com efeito de transparência ao rolar a página (*scroll*).
*   **Efeitos Visuais e Transições:** Animações sutis em CSS para transmitir a sensação de sofisticação e velocidade associada à marca.
